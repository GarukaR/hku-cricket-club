DIRECTION 1 — “MATCHDAY”. Structure borrowed from a scoreboard: the scoreline is the largest object on the page, fixtures scroll as a rail, and one loud colour (ball red) carries every call to action while everything else stays quiet.
Commits deliberately to a single dark world — a floodlit-evening feel — so it does not offer a light theme.
COLOURS ARE NOW THE CLUB'S OWN — every hue on this page is taken from the crest (red, gold, green, willow), with lightness adjusted until each text/background pair clears WCAG AA. The crest hexes were read off a phone screenshot of the logo, so they are close but not exact; the original vector file would let them be sampled properly. Fonts are system stacks because this sandbox blocks external fonts; the production site self-hosts real faces via next/font. Scores and dates are invented sample content.
