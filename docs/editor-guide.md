# Running the website

For whoever is on the committee this year. You should not need this — the
admin panel explains itself, field by field, and the dashboard lists the
common tasks the moment you sign in. This is the backup, for the one time a
screen leaves you unsure. A short
[recording covering the same ground](https://drive.google.com/file/d/1PXH7kTAjWL-Zolo5bjzXwT_GNIO2jesm/view?usp=drive_link)
sits alongside this file.

If you are reading this because you have just been handed the club's
accounts, start at **Handing over**, below.

## Signing in

The admin panel is at the CMS's own address — ask the outgoing committee
member for it, along with your account. Everyone with an account can do
everything here; there are no restricted roles to worry about.

## The one thing you will do most: import a match

After a match, someone scores it on CricClubs. Getting it onto the website is
two clicks:

1. Open the match on CricClubs and press its own export button. This
   downloads a file — do not retype anything by hand.
2. In the admin panel, click **Import a scorecard** in the sidebar, and
   choose that file.

The screen shows you the whole scorecard before anything is saved, so you can
check it against the real one. Then one of two things happens:

- **Nothing looks wrong.** A button says **Publish this match**, and pressing
  it puts the match on the live site within seconds.
- **Something needs a decision.** The screen tells you exactly what — a
  player's name it does not recognise, a total that does not add up, or a way
  of getting out it has never seen. Answer what it asks (usually: "who is
  this?"), and the file is remembered — the same spelling will not be asked
  about again. The match saves as a draft either way; a held draft is never
  news, but the panel makes it hard to miss on the way in.

## A match nobody exported

The **sunday social** side is not scored on CricClubs at all, so its matches
never go through the import screen. To enter one — or to fix a mistake in a
match already saved — open the Match itself and use its **Scorecard** tab. It
is one row per player, and a player who neither batted nor bowled still gets a
row: leaving both boxes unticked is how the panel knows they were there
without doing anything, which is different from not playing at all.

## Somebody wants to join

Messages from the site's own enquiry form land in **Enquiries**, newest
first. Reply however the club normally replies — by email or phone — and
mark the enquiry **Actioned** once you have. That status is the whole
to-do list; there is no separate notification to miss.

## Before a new season starts

Add the year to **Seasons** — written as the club writes it, `2025/26` — before
the first match of it is entered. Do this in September, not mid-season; a
match entered against a season that does not exist yet cannot be saved.

## A photograph

Upload it to **Media**, and describe what it shows rather than naming the
file — "Sandy Bay, second innings, 2025/26" rather than `IMG_4021.jpg`. The
site is static, so a photograph appears live within seconds of saving it, the
same as a match.

## Handing over

At the end of your year:

1. Add an account for whoever is taking over, in **Users**.
2. Remove the accounts of whoever is stepping down.
3. Point them at this file and the recording beside it — and tell them, as
   this file is telling you, that they should not need either.

## If something looks genuinely broken

This guide, and the recording, cover the ordinary week. If the admin panel
will not load at all, or a page on the public site looks wrong in a way
nothing here explains, that is a question for whoever the club keeps as a
technical contact — not something to guess at.
